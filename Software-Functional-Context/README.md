# Software Functional Context

[Read the skill instructions](SKILL.md).

Inspect a software repository and generate an **evidence-based** description of its current functional behavior. The deliverables are a detailed domain package and a standalone compact handoff for readers without source access.

~~~text
Document what the repository currently does, including actors, rules and workflows.
Distinguish observed behavior from inferred behavior and unknowns.
Produce a portable compact summary for a downstream ticket reviewer.
~~~

**Confidentiality:** generated context may disclose internal business rules, permissions, integrations or code structure. Save it to an authorized project workspace and obtain permission before public publication.

Project-specific generated documentation is intentionally not included in this repository. Store any such output separately, and publish it only with the relevant owner's authorization.

For ticket evaluation see [Ticket Readiness](../Ticket-Readyness/SKILL.md).
