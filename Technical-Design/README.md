# Technical Design

[Read the skill instructions](SKILL.md).

Transform an approved requirement or conceptual analysis into a practical design that fits an existing codebase. Consider only the relevant architecture, data, APIs, transactions, concurrency, security, observability, tests, deployment and failure handling.

~~~text
Design the implementation of this validated primary-subscription invariant.
Inspect existing patterns and identify concurrent-update risks.
Keep the design proportional. Do not implement production code yet.
~~~

If business rules are still ambiguous, return blocking questions rather than inventing answers. Related: [Conceptual Analysis](../Conceptual-Analysis/SKILL.md) and [Architectural Audit](../Architectural-Audit/SKILL.md).
