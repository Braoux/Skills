# Organic Acquisition Experiments

[Skill instructions](SKILL.md)

**When to use:** once a reliable first-use journey exists and you are ready to learn which audiences respond to the value proposition.

**No-key inputs:** your own prior content, manually provided comments, existing URLs, local analytics, public documentation when already available. No Search Console, social platform or keyword API required.

**Metric ladder:** impressions (optional) → qualified visits → usable first analyses → observed returns → paid interest when available. The middle and final steps matter more than impressions.

**Example invocation:** `/organic-acquisition-experiments Prépare trois campagnes organiques pour BotDiff, sans publier, sans scraping, sans achat publicitaire ni clé API.`

**Manual verification scenarios:** (1) no real search volumes → label keyword priority speculative; (2) campaign has 10,000 views, 0 observed analyses → weak product traffic evidence; (3) site is unstable → recommend postpone outreach; (4) subreddit bans self promotion → propose an allowed educational alternative.

**Related:** `activation-retention-audit` for quality of visits and `pricing-offer-validation` for paying-demand evidence.

## No-key execution contract

Use this skill in an already-running agent by providing existing local files, public materials already available, or anonymized data. No `OPENAI_API_KEY`, `requires.env`, additional network API, integration or paid account is required. When evidence is absent, the skill produces a collection plan instead of imaginary conclusions. Any model credentials needed to operate the user's chosen AI agent are outside the skill and are never requested by this skill.
